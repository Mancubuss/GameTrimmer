# GameTrimmer

GameTrimmer — це утиліта для очищення ігрових бібліотек (Steam, Epic, GOG, Ubisoft, EA) від непотрібних файлів. Програма допомагає знайти та безпечно видалити:
- Редистрибутиви (vcredist, directx, тощо)
- Зайві локалізації (зі збереженням keep-list мов)
- Документацію та файли довідки
- Інші допоміжні файли, які не потрібні для запуску ігор

## Можливості

- Автоматичне виявлення бібліотек Steam/Epic/GOG/Ubisoft/EA + ручні теки
- Швидке сканування: прямий парсинг $MFT (NTFS) на HDD, walkdir на SSD
- Кеш результатів у SQLite
- Движок правил локалізацій із запобіжниками проти хибних спрацювань
- Видалення лише за явним підтвердженням користувача
- Темна тема, High-DPI, один портабельний exe

## Стек

Rust + egui (eframe), rusqlite, walkdir + rayon. Воркспейс:
- `crates/core` — сканування, правила, кеш
- `crates/app` — GUI

## Збірка

```
cargo build --release
```

> Примітка: збірка йде в зовнішній target-каталог (див. `.cargo/config.toml`) через кирилицю в шляху проєкту.

## Історія

Початковий прототип на C++20 + Qt 6.8 збережено в гілках `legacy/cpp-qt` та `winapi-version`.
