# GameTrimmer

GameTrimmer - це утиліта для очищення Steam-бібліотеки від непотрібних файлів. Програма допомагає знайти та видалити:
- Редистрибутиви (vcredist, directx, тощо)
- Системні компоненти
- Документацію та файли довідки
- Інші допоміжні файли, які не потрібні для запуску ігор

## Можливості

- Автоматичний пошук теки Steam
- Виявлення всіх бібліотек Steam
- Сканування файлів та тек
- Відображення розмірів файлів
- Сортування за розміром
- Безпечне видалення з підтвердженням

## Вимоги

- Windows 10/11
- Visual Studio 2022
- Qt 6.8.2
- CMake 3.16 або новіше

## Збірка

1. Клонуйте репозиторій
2. Запустіть `build.bat`
3. Готово!
