- **Епік борди:** [GT-EP11 (id: 321)](http://127.0.0.1:3456) · «Комерціалізація, зміна ліцензії та дистрибуція у Steam і на інших платформах»

## 1. Головні висновки (Executive Summary)

1. **Повна ліцензійна чистота:** Жодна пряма чи транзитивна залежність у `Cargo.lock` не містить Copyleft-ліцензій (GPL/AGPL/LGPL-static). Автор має 100% право випускати наступні комерційні білди під власною пропрієтарною ліцензією за моделлю **Open-Core / Dual-Licensing**.
2. **Оптимальна бізнес-модель:** **Pay-Once Premium у Steam ($6.99)** у поєднанні з відкритим базовим ядром на GitHub (`gametrimmer-core` під MIT). Це забезпечує максимальну довіру спільноти та знімає бар'єр купівлі в Steam.
3. **Фінансовий потенціал:**
   - **Консервативний сценарій (1 рік):** 3,000 копій → **$8,010 (~332k грн)** чистого прибутку на рахунок ФОП.
   - **Базовий реалістичний сценарій (1 рік):** 25,000 копій → **$66,750 (~2.77M грн)** чистого прибутку. Накопичувально за 3 роки: **$200,250 (~8.31M грн)**.
   - **Оптимістичний сценарій (1 рік):** 100,000 копій → **$267,000 (~11.08M грн)** чистого прибутку.
4. **Податкова оптимізація:** Форма W-8BEN (угода США-Україна) знижує утримання податку США з 30% до 10%. Зарахування на рахунок ФОП 3-ї групи (5% ЄП + військовий збір) забезпечує збереження **~38.2% від повної вартості копії у США** у вигляді чистого прибутку розробника (Unit Waterfall).
5. **Мультиплатформний Roadmap:**
   - *Фаза 1:* Steam Store (Steamworks SDK, Steam Pipe) + Microsoft Store (MSIX з автоматичною SmartScreen-довірою).
   - *Фаза 2:* D2C через Lemon Squeezy / Paddle (офлайн-ліцензії Ed25519) + itch.io (Butler).
   - *Фаза 3:* Epic Games Store + розширені B2B пресети.

## 2. Результати дослідження окремих спайків

### 2.1. Спайк GT-147: Ліцензійний аудит та стратегія переліцензування
* **Аудит залежностей:** Перевірено всі крейти: `rusqlite` (MIT/Blessing Public Domain), `windows-rs` (MIT/Apache-2.0), `egui`/`eframe` (MIT/Apache-2.0), `rayon` (MIT/Apache-2.0), `ntfs` (MIT/Apache-2.0), `trash` (MIT), `zip` (MIT/Apache-2.0, zlib-rs без системних C-ліб), `dunce` (CC0/Apache-2.0/MIT).
* **Право на зміну ліцензії:** Оскільки 100% авторського права належить розробнику, ліцензія MIT для релізу 1.0.0 є невиключною. Автор має право випускати версії 1.1+ як комерційний закритий продукт.
* **Захист від юридичних ризиків:** До `CONTRIBUTING.md` впроваджується DCO (Developer Certificate of Origin) та обов'язковий CLA (Contributor License Agreement), що закріплює за автором право комерціалізації будь-яких зовнішніх пулл-реквестів.

### 2.2. Спайк GT-148: Вихід у Steam Store (Steam Direct & Steamworks)
* **Процес онбордингу:** Сплата $100 Steam Direct Fee (повертається після досягнення $1,000 виторгу). Проходження податкового інтерв'ю з українським РНОКПП (W-8BEN, ст. 12 Конвенції про уникнення подвійного оподаткування).
* **Легітимність SSA/SDA:** GameTrimmer діє виключно за явною командою користувача (User-Driven Action), не декомпілює захищені компоненти Steam, не чіпає DRM та дозволяє відновити будь-які файли через штатну перевірку цілісності Steam ("Verify integrity of game files").
* **Steamworks SDK (`steamworks-rs`):** Реалізується "м'яка" ініціалізація (Graceful Init). Бінарник запускається як у клієнті Steam (підтримуючи Steam Cloud та ачівки), так і повністю автономно без запущеного клієнта.
* **Steam Pipe CI/CD:** Автоматизований деплой депотів через GitHub Actions workflow (`game-ci/steam-deploy`).

### 2.3. Спайк GT-149: Альтернативні канали (MS Store, itch.io, D2C)
* **Microsoft Store (MSIX):** Головна перевага — **100% автоматична довіра Windows SmartScreen без необхідності купівлі дорогих EV Code Signing сертифікатів**. Пакування здійснюється через маніфест з розширеними правами `broadFileSystemAccess` та `runFullTrust`.
* **itch.io:** Деплой через `butler push` для залучення інді-спільноти за моделлю Pay-What-You-Want.
* **D2C (Lemon Squeezy / Paddle):** Модель Merchant of Record бере на себе 100% податкової звітності та сплати VAT/GST у більш ніж 100 країнах світу, надсилаючи один регулярний валютний платіж на рахунок ФОП.

### 2.4. Спайк GT-150: Юридичний комплаєнс, EULA та товарні знаки
* **Commercial EULA:** Чітко сформульовані пункти: «AS-IS» (відмова від прямих і непрямих гарантій), суворе обмеження відповідальності за можливу втрату даних та фіксація принципу «користувач є єдиною стороною, яка санкціонує видалення».
* **Anti-Cheat Safe Shield:** Офіційна декларація сумісності з VAC, EAC, BattlEye, Vanguard та Ricochet: нульова модифікація пам'яті, нульове втручання у виконувані файли, пасивне очищення файлів лише при закритій грі.
* **Nominative Fair Use:** Дисклеймер щодо товарних знаків Valve, Epic Games, Ubisoft, EA тощо в About та на сторінках магазинів, що виключає претензії правовласників щодо асоціацій з їхніми брендами.
* **Privacy Policy:** Декларація повної відсутності збору персональних даних (No PII) та роботи без зовнішніх мережевих запитів (100% GDPR-compliant).
* **Податкова форма в Україні:** ФОП 3-тя група (єдиний податок 5% + військовий збір), основні КВЕД: 58.29 (Видання іншого ПЗ), 62.01 (Комп'ютерне програмування), 62.02 (Консультування). Робота з ЗЕД за Законом № 4496.

### 2.5. Спайк GT-151: Реліз-інжиніринг, Code Signing та ліцензійні ключі
* **Code Signing:** Використання Microsoft Azure Trusted Signing (~$10/місяць) для автономних `.exe` білдів замість застарілих фізичних USB-токенів ($400-650/рік) або автоматичне безкоштовне підписання через Microsoft Store MSIX.
* **Офлайн-ліцензування на Ed25519:** Криптографічна валідація ліцензійного JSON/сертифіката в Rust за 32-байтним публічним ключем автора. 100% робота без інтернету, відсутність нав'язливого DRM.
* **Win32 Atomic Updater:** Безпечний механізм автооновлення для standalone-версії через атомне перейменування файлів у Windows без блокування процесу.
