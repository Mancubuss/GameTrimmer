# Game Space Optimizer - Специфікація проекту

## Призначення
Програма для оптимізації дискового простору, що зайнятий встановленими іграми. Виконує це шляхом переміщення некритичних файлів у тимчасове сховище.

## Ключові вимоги

### Функціональні вимоги
1. Автоматичне виявлення встановлених ігор:
   - Steam
   - EPIC Games
   - GOG
   - Інші платформи (розширюване)

2. Категорії файлів для оптимізації:
   - Редистрибутиви бібліотек
   - Мовні файли
   - Документація
   - Інші некритичні файли

3. Безпечне управління файлами:
   - Переміщення замість видалення
   - Збереження структури папок
   - Можливість відновлення
   - Розміщення тимчасового сховища на тому ж диску

### Нефункціональні вимоги
1. Портабельність:
   - Не потребує інсталяції
   - Автономна робота
   - Мінімальні зовнішні залежності

## Технічні рішення

### MVP версія
- Мова програмування: Python
- Технічний стек:
  - UI: tkinter
  - Файлові операції: os, shutil
  - Робота зі Steam: vdf
  - Робота з реєстром: winreg
  - Створення exe: PyInstaller

### Майбутні версії (за необхідності)
- Можлива міграція на C++ (Qt) або C# (.NET) для покращення продуктивності
- Оптимізація швидкості сканування файлів
- Розширення підтримки ігрових платформ

## План розробки MVP

1. Базова архітектура:
   - Модуль сканування директорій
   - Система виявлення ігрових інсталяцій
   - Управління тимчасовим сховищем

2. Основний функціонал:
   - Виявлення некритичних файлів
   - Система категоризації файлів
   - Механізм безпечного переміщення

3. Користувацький інтерфейс:
   - Список виявлених ігор
   - Вибір категорій файлів
   - Управління операціями
   - Відображення прогресу

4. Безпека та відновлення:
   - Логування операцій
   - Система відновлення файлів
   - Перевірка цілісності
