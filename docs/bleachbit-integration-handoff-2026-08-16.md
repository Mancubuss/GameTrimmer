# Дослідження інтеграції GameTrimmer з BleachBit (Handoff) — 2026-08-16

Цей документ підсумовує результати дослідження можливості конвертації правил та даних GameTrimmer у формати для BleachBit (CleanerML XML та Winapp2.ini).

---

## 1. Контекст та мета

**Мета:** Визначити, чи можна сконвертувати правила GameTrimmer (включаючи `rules.json`, правила локалізацій `l10n_rules.json` та мовні переклади описів) у формати, підтримувані проєктом [BleachBit](https://www.bleachbit.org/) ([CleanerML](https://docs.bleachbit.org/cml/cleanerml.html), [example_cleaner.xml](https://github.com/bleachbit/bleachbit/blob/master/doc/example_cleaner.xml)), а також оцінити використання наявної бази `gametrimmer.db` для експорту готових правил очищення.

---

## 2. Підсумкові висновки

| Об'єкт дослідження | Можливість прямої конвертації | Причина / Особливості |
| :--- | :--- | :--- |
| **`rules.json` (Редистрибутиви, Доки, Бонуси)** | **Частково** | Можна згенерувати `<action command="delete" regex="..."/>`, але CleanerML не підтримує `max_depth` (ризик видалення ресурсів рушія) та динамічне виявлення директорій ігор. |
| **`l10n_rules.json` (Локалізації)** | **Ні** (в сирому вигляді) | Потребує алгоритмічного багаторівневого скорингу (`level_a/b/c`), стоп-слів та динамічного вибору мов користувача (Keep List), що неможливо описати статичним XML. |
| **Переклади описів правил (`desc: { en, uk }`)** | **Ні** (інший пайплайн) | CleanerML не підтримує inline JSON-словники перекладів. BleachBit використовує **GNU gettext** (`.po`/`.pot`/Weblate). |
| **Динамічний пошук бібліотек ігор (Steam/Epic/GOG)** | **Ні** (через CleanerML/Winapp2) | CleanerML не вміє читати реєстр у змінні шляхів і не має парсерів `libraryfolders.vdf` чи JSON-маніфестів. Можливо лише через кастомний Python-плагін. |
| **Готова база `gametrimmer.db`** | **ТАК (100% практична сумісність)** | База містить уже готові точні абсолютні шляхи до 720k+ файлів для 1,600+ ігор. З неї можна генерувати персоналізований XML/INI для BleachBit. |

---

## 3. Аналіз підходів конвертації

### Підхід 1. Конвертація декларативних правил (`rules.json` + `l10n_rules.json`)
* **Проблема глибини (`max_depth`):** У GameTrimmer правило на бонуси/редистрибутиви діє лише на глибині $\le 2$ або $\le 4$ від кореня гри. У CleanerML `walk.all` / `deep` заглиблюються нескінченно, що призведе до видалення внутрішніх компонентів рушіїв (наприклад, `Engine/Plugins/QtQuick/Extras`).
* **Проблема мовних правил:** Перетворення 2-літерних кодів (`de`, `fr`, `es`) на прості Regex у BleachBit видалить критичні файли гри (`node_modules`, `fr_engine.dat`, `code.dll`).

### Підхід 2. Експорт зліпка з `gametrimmer.db` (Рекомендовано)
Утиліта GameTrimmer виконує сканування та зберігає результат у SQLite:
* **Знайдено в реальній базі:** 1 603 гри, 720 623 знахідки (~760 ГБ потенційної економії).
* **Мови:** німецька (111k), французька (109k), іспанська (96k), італійська (78k), російська (65k), японська (47k), польська (39k) тощо.

#### Структура експорту у CleanerML XML:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<cleaner id="gt_cyberpunk2077" os="windows">
  <label>Game: Cyberpunk 2077</label>
  <description>Generated by GameTrimmer</description>
  
  <option id="redist">
    <label>Redistributables</label>
    <description>Remove installer dependencies</description>
    <action command="delete" search="walk.top" path="D:\SteamLibrary\steamapps\common\Cyberpunk 2077\_CommonRedist"/>
  </option>

  <option id="loc_de">
    <label>Localization: German</label>
    <description>Remove German voice and text files</description>
    <action command="delete" search="file" path="D:\SteamLibrary\steamapps\common\Cyberpunk 2077\archive\pc\content\lang_de_voice.archive"/>
  </option>
</cleaner>
```

#### Ключова оптимізація продуктивності BleachBit:
* **Агрегація папок:** Замість 720 000 окремих тегів `<action search="file".../>` (від чого інтерфейс BleachBit на GTK/Python зависне), папки `redist_folder`, `docs_folder` та `group_dir` повинні згортатися у `search="walk.top"` / `search="walk.all"`. Це зменшує розмір правил до кількох тисяч рядків.
* **Keep List:** Фільтрація мов за списком винятків користувача (наприклад `WHERE lang_tag NOT IN ('uk', 'en')`).

## 4. Виявлення шляхів встановлення ігор

Користувачі мають ігри на різних дисках і в різних лаунчерах:
1. **Чому CleanerML не може сам:** CleanerML оперує фіксованими шляхами (`%ProgramFiles%`, `%APPDATA%`, `~`). Він не має доступу до реєстру для підстановки змінних і не вміє парсити VDF/JSON.
2. **Як це реалізувати:**
   * **Варіант А (GameTrimmer Export):** GameTrimmer (де реалізовано 14 провайдерів бібліотек: Steam, Epic, GOG, EA, Ubisoft, Battle.net тощо) формує персоналізований XML під конкретний ПК у папку `%APPDATA%\BleachBit\cleaners\gametrimmer.xml`.
   * **Варіант Б (Кастомний Python Cleaner у BleachBit):** Написати Python-модуль `Cleaner` у складі BleachBit, який через `winreg` зчитує шлях до Steam та парсить `libraryfolders.vdf` у рантаймі.

---

## 5. План можливої реалізації (Next Steps)

Якщо буде прийнято рішення додати експорт для BleachBit:
1. **CLI команда або кнопка в UI:** Додати в GameTrimmer команду `gametrimmer export-bleachbit [--keep uk,en] [--out-dir %APPDATA%/BleachBit/cleaners]`.
2. **Генератор CleanerML:**
   * Групувати за іграми (`games.id` -> `<cleaner id="gt_...">`).
   * Групувати папки за `group_dir` / `redist_folder` для скорочення обсягу XML.
   * Розбивати мовні знахідки на окремі опції `<option id="loc_{lang}">`.
3. **Підтримка `winapp2.ini`:** Опціональна генерація компактного INI-файлу для користувачів Winapp2/BleachBit.
