# Епік GT-EP16: Модульна зовнішня система локалізації UI (Community-Driven External Localization & i18n Engine)

- **Дата створення:** 18 серпня 2026 року
- **Батьківський проект:** GameTrimmer (v1.1.0+)
- **Епік на борді:** [GT-EP16 (id: 360)](http://127.0.0.1:3456) · «Модульна зовнішня система локалізації UI (Community-Driven External Localization & i18n Engine)»
- **Статус епіку:** В роботі / Реалізація (Ponytail Lean Architecture)
- **Головна мета:** Повне винесення інтерфейсних рядків та динамічних повідомлень за межі скомпільованого `.exe` у відкриті зовнішні файли (`locales/*.json`), що дозволить користувачам і спільноті вільно виправляти помилки, адаптувати термінологію та створювати нові локалізації без перезбирання програми з вихідного коду.

---

## 1. Головне резюме (Executive Summary)

Наразі інтерфейс GameTrimmer локалізовано двома мовами (англійська та українська), однак усі рядки (`Strings`) та функції повідомлень (`messages.rs`) зашиті безпосередньо у вихідний код Rust та компілюються всередину бінарного файлу `gametrimmer.exe`.

У рамках епіку GT-EP16 реалізується **лаконічна, мінімалістична та надійна система (Ponytail-архітектура)**:
1. **Типізований `struct Strings` з прямим `serde_json` парсингом:** Рядки десеріалізуються безпосередньо в структуру інтерфейсу. Жодних `HashMap` lookup'ів у щокадровому циклі egui — виклики `s.btn_scan_libraries` залишаються незмінними.
2. **Zero-Broken-UI Shield:** Еталонні пакети `locales/en.json` та `locales/uk.json` вшиті у бінарник через `include_str!`. Якщо на диску немає файлів або бракує ключів, застосунок автоматично використовує вбудовані англійські або українські оригінали.
3. **Легка плюралізація:** Компактний 15-рядковий helper для германських (1 / other) та слов'янських (1 / 2-4 / 5+) мов.
4. **Простий UI:** Випадаючий список `ComboBox` у `Settings -> General` із переліком знайдених файлів у `locales/` + кнопка швидкого переходу до теки локалізацій.

## 2. Формат файлів та структура каталогів

Файли розміщуються у теці `locales/` поруч із `gametrimmer.exe`:

```
gametrimmer/
├── gametrimmer.exe
├── gametrimmer.ini
├── rules.json
├── l10n_rules.json
└── locales/
    ├── en.json                      <-- Еталонна англійська
    ├── uk.json                      <-- Офіційна українська
    ├── pl.json                      <-- Додана користувачем польська (опціонально)
    └── gametrimmer.template.json    <-- Шаблон для створення нових мов
```

## 3. Збереження аудиторій та діагностики

- `gametrimmer.log` та бандли **завжди** пишуться англійською мовою (через `Reported { log, shown }`).
- Інтерфейс користувача відображається активною вибраною мовою.
