# Обговорення проекту GameTrimmer (05.01.2024 19:30)

## Основні вимоги до програми

1. **Автоматичне виявлення ігор:**
   - Пошук встановлених ігор у різних клієнтах (Steam, Epic, GOG, etc.)
   - Можливість додавання власних шляхів для сканування

2. **Аналіз файлів:**
   - Категорії: редистрибутиви, документація, мовні файли
   - Гнучкі налаштування критеріїв пошуку

3. **Безпечне управління файлами:**
   - Резервне копіювання за замовчуванням
   - Створення прихованої директорії _GameTrimmer
   - Збереження структури каталогів при переміщенні

4. **Користувацький інтерфейс:**
   - Відображення прогресу сканування
   - Можливість вибору файлів/категорій
   - Попередження при вимкненні резервного копіювання

## Технічні деталі

### Steam
Шляхи до встановлених ігор зберігаються у файлі steamapps/libraryfolders.vdf:
- AppID та розмір для кожної гри
- Шляхи до всіх бібліотек Steam

### План реалізації MVP
1. Парсинг VDF файлу (бібліотека vdf)
2. Отримання назв ігор через Steam Web API
3. Збереження даних у JSON форматі
