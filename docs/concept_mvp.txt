Я хочу створити програму, яка буде аналізувати файли ігор, що зберігаються на жорсткому диску користувача, і надавати можливість видалити серед них некритичні для функціональності: редистрибутиви рантаймів, документацію, додаткові промо та бонусні матеріали, а також неактуальні для користувача файли локалізацій.

Програма буде складатися із наступних модулів:

1. Пошук і аналіз файла steamapps/libraryfolders.vdf на предмет знаходження бібліотек Steam
2. Збереження вищевказаних шляхів у локальну базу даних sqlite3 в окремій таблиці game_libraries
3. Індексація файлів за шляхами з п.2 у базі sqlite3 в окремій таблиці game_files_steam
4. Аналіз індексованих файлів на предмет відповідності регулярним виразам з Додатку 1
5. Аналіз індексованих файлів на предмет вмісту в їх імені та/або частини шляху ідентифікаторів мов відповідно стандартам сімейств ISO 639, ISO 15924, ISO 3166, IETF, без урахування регістру
6. Вивод ідентифікованих файлів у вигляді зручного списку з розділенням на категорії і можливістю обрати кожен файл або папку або зняти виділення. За промовчанням всі виведені файли мають бути виділені. 
7. Видалення виділених файлів

Я також хочу, щоб програма писалася на с++, а кожен окремий модуль був відокремлений у dll.
Також програма має бути портабельною та мати основною темну тему інтерфейсу. Інтерфейс має бути сучасним, мінімалістичним, масштабуємим відповідно до налаштувань інтерфейсу Windows під різні DPI.

Додаток 1: Регулярні вирази визначення зайвих файлів.

# redistFolders
"^3rd$" # Multiple redistributables
"^.*(dependenc|prereq|install|redist).*$" # Multiple redistributables
"^(directx|.*dx(setup|redist|install).*)$" # MS DirectX
"^(msvc.*|vcredist)$" # MS Visual C++ Runtimes
"^(g4w|wmfdist11|wmf)$" # Obsolete MS Installers

# redistFiles
"^(UplayInstaller|UbisoftConnectInstaller|EAappInstaller)\\.exe$" # Distribution Platforms installers
"^(wic_(x64|x86)|xpsepsc|.*netfx).*\\.(exe|msi)$" # MS .NET Framework
"^dxwebsetup\\.exe$" # MS DirectX Web Installer
"^(vcredist).*\\.exe$" # MS Visual C++ Redist
"^(gfwl.*|arcadeinstall.*|gamespyinstaller.*)\\.exe$" # Obsolete platform installers
"^.*kb\\d{5,8}.*\\.exe$" # MS System Updates
"^.*msxml.*\\.exe$" # MS XML Redist
"^(physx).*\\.exe$" # NVidia PhysX
"^(openalweax|oalinst)\\.exe$" # OpenAL
"^(rapture3d_).*\\.exe$" # Rapture 3D
"^amd_.*setup.*\\.exe$" # AMD Dual-Core Optimizer
"^.*battleeye.*\\.exe$" # BattlEye Anti-Cheat Engine

# extraFolderPatterns
"^(support|help)$" # Support files and redistributables
"^(bonus|artbook|soundtrack|extras)$" # Bonus materials
"^(docs|documents|manuals?)$" # Documentation

# extraFilesPatterns
"^.+\\.(pdf|rtf)$" # Documentation
"^(thumbs\.db|testapp.*\.exe)$" # Development leftovers
