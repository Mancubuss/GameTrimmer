🎮 GT-148 Публікація утиліти в Steam: Steam Direct, правила Valve, Steamworks та Steam Pipe

▼

Організаційні вимоги:

  • Steam Direct Fee: $100 за кожний зареєстрований App ID (повертається у першій виплаті Valve після досягнення $1,000 валового виторгу).
  • Податкове структурування: Заповнення форми W-8BEN із зазначенням українського РНОКПП (TIN) та посиланням на ст. 12 Конвенції про уникнення подвійного оподаткування знижує податок у США з 30% до 10%.
  • Виплати: Щомісячний банківський переказ SWIFT на валютний рахунок ФОП IBAN у USD (відповідно до ЗУ № 4496 без потреби паперових актів).

Легітимність за угодами Valve (SSA/SDA): Категорія Software → Utilities. GameTrimmer діє суто за ініціативою користувача (User-Driven Action), не порушує цілісність клієнта Steam та не перехоплює системні процеси. Усі зміни можуть бути відновлені штатною перевіркою файлів Steam.

Технічна інтеграція: Інтеграція steamworks-rs із "м'яким стартом" (Graceful Init), що дозволяє бінарнику запускатися навіть якщо клієнт Steam вимкнено.

⚖️ GT-150 Юридичний комплаєнс, EULA, товарні знаки та податкова модель

▼

Чотири стовпи правового захисту:

  1. Commercial EULA: Чітке положення «AS-IS» (без гарантій), обмеження відповідальності за можливі збої та підтвердження того, що утиліта діє виключно за явною командою користувача.
  2. Anti-Cheat Safe Shield: Офіційний дисклеймер про несумісність із читерством: нульовий доступ до пам'яті, нульова модифікація .exe/.dll, очищення тільки статичних файлів при вимкненій грі.
  3. Nominative Fair Use: Законне використання назв платформ (Steam, Epic, Ubisoft, EA) суто для позначення шляхів каталогів без створення враження партнерства чи схвалення.
  4. Privacy Policy (No PII): 100% GDPR-сумісність — утиліта не збирає персональні дані, не має зовнішньої телеметрії та працює повністю офлайн.

Податкова модель: ФОП 3-ї групи (Україна, 5% єдиного податку + військовий збір). КВЕД 58.29 (Видання іншого ПЗ), 62.01 (Програмування), 62.02 (Консультування).

🔑 GT-151 Реліз-інжиніринг, Code Signing та система ліцензійних ключів

▼

Підпис коду (Code Signing):

  • MSIX (Microsoft Store): Підписується Microsoft безкоштовно та дає миттєву довіру Defender.
  • Microsoft Azure Trusted Signing: Оптимальний вибір для standalone .exe (~$9.99/міс замість $400-650/рік за фізичні токени), повна інтеграція з GitHub Actions.

Офлайн-ліцензування на Ed25519: Криптографічна валідація ліцензійного JSON/ключа на базі асиметричного підпису. Публічний ключ вшитий у Rust-бінарник, перевірка здійснюється на 100% автономно без потреби постійного інтернет-з'єднання.

Win32 Atomic Auto-Updater: Механізм заміни виконуваного файлу через атомне перейменування .new → .old без блокування запущеного процесу.

GameTrimmer is engineered from the ground up to be 100% compliant and safe with modern gaming anti-cheat solutions, including Valve Anti-Cheat (VAC), Easy Anti-Cheat (EAC), BattlEye, Riot Vanguard, and Ricochet.

🦀 Офлайн-валідація ліцензійних ключів на Ed25519 (Rust)

Повний модуль для автономної перевірки криптографічного підпису ліцензії

use ed25519_dalek::{Signature, Verifier, VerifyingKey};
use serde::{Deserialize, Serialize};

/// Вшитий 32-байтний публічний ключ автора
pub const EMBEDDED_PUBLIC_KEY: [u8; 32] = [
    0x8e, 0x4f, 0x1b, 0x2c, 0x3d, 0x4e, 0x5f, 0x60,
    0x71, 0x82, 0x93, 0xa4, 0xb5, 0xc6, 0xd7, 0xe8,
    0xf9, 0x0a, 0x1b, 0x2c, 0x3d, 0x4e, 0x5f, 0x60,
    0x71, 0x82, 0x93, 0xa4, 0xb5, 0xc6, 0xd7, 0xe8,
];

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LicensePayload {
    pub licensee_name: String,
    pub licensee_email: String,
    pub tier: String,          // "Pro", "Commercial", "Lifetime"
    pub issued_at_unix: u64,
    pub expires_at_unix: u64,  // 0 = безстрокова
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LicenseCertificate {
    pub payload: LicensePayload,
    pub signature_base64: String,
}

pub struct LicenseValidator {
    verifying_key: VerifyingKey,
}

impl LicenseValidator {
    pub fn new() -> Result {
        let verifying_key = VerifyingKey::from_bytes(&EMBEDDED_PUBLIC_KEY)
            .map_err(|_| "Invalid embedded public key")?;
        Ok(Self { verifying_key })
    }

    pub fn verify_license(&self, cert_json: &str, current_unix_time: u64) -> Result {
        let cert: LicenseCertificate = serde_json::from_str(cert_json)
            .map_err(|_| "Invalid JSON format")?;

        let canonical_payload = serde_json::to_vec(&cert.payload)
            .map_err(|_| "Canonical serialization failed")?;

        use base64::Engine;
        let sig_bytes = base64::engine::general_purpose::STANDARD
            .decode(&cert.signature_base64)
            .map_err(|_| "Invalid base64 signature")?;

        let signature = Signature::from_slice(&sig_bytes)
            .map_err(|_| "Invalid signature length")?;

        self.verifying_key
            .verify(&canonical_payload, &signature)
            .map_err(|_| "Signature mismatch / invalid license key")?;

        if cert.payload.expires_at_unix != 0 && current_unix_time > cert.payload.expires_at_unix {
            return Err("License has expired");
        }

        Ok(cert.payload)
    }
}

📦 GitHub Actions Workflow: Автодеплой у Steam Pipe

.github/workflows/steam_deploy.yml

name: Steam Deploy

on:
  push:
    tags: ["v*"]
  workflow_dispatch:

jobs:
  steam-deploy:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          targets: x86_64-pc-windows-msvc

      - name: Build Steam Binary
        run: cargo build --release --workspace --features steam

      - name: Stage Artifacts
        shell: pwsh
        run: |
          New-Item -ItemType Directory -Force -Path steam_stage
          Copy-Item target/release/gametrimmer.exe steam_stage/
          Copy-Item rules.json steam_stage/
          Copy-Item l10n_rules.json steam_stage/
          Copy-Item THIRD-PARTY-NOTICES.md steam_stage/
          Copy-Item LICENSE steam_stage/

      - name: Deploy to Steam
        uses: game-ci/steam-deploy@v3
        with:
          username: ${{ secrets.STEAM_USERNAME }}
          password: ${{ secrets.STEAM_PASSWORD }}
          configVdf: ${{ secrets.STEAM_CONFIG_VDF }}
          appId: ${{ secrets.STEAM_APP_ID }}
          buildDescription: "v${{ github.ref_name }} via GitHub Actions"
          rootPath: steam_stage
          depot1Path: .
          releaseBranch: default
