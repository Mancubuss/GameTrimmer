# tests/corpus/corpus.tsv — корпус шляхів для движка визначення локалізацій

Згенеровано інструментом `crates/core/examples/corpus_collect.rs` (запуск:
`cargo run -p gametrimmer-core --example corpus_collect`) шляхом read-only
сканування реальних бібліотек Steam на цій машині:

- `G:\SteamLibrary`
- `H:\SteamLibrary`
- `F:\SteamLibrary` (велика бібліотека — відбирається підмножина, див. нижче)
- `d:\portableapps\portable\games\steam`

Інструмент нічого не пише і не видаляє на цих дисках — лише читає реєстр,
`libraryfolders.vdf`, `appmanifest_*.acf` та обходить дерево тек кожної гри
(`scanner::scan_dir`), у пам'яті, без бази даних. Єдиний файл, який він
записує — це `tests/corpus/corpus.tsv`.

**ВАЖЛИВО:** цей корпус — фіксатор регресій для `crates/core/src/langdetect/`.
`corpus_collect.rs` навмисно НЕ використовує `langdetect` — він реалізує
власний невеликий токенізатор/словник лише для цілей збору корпусу. Це
спрощене чернеткове наближення до того, що робить рушій, а не друга його
реалізація: інструмент, який збирає тестові дані, не має залежати від коду,
який ці дані перевіряють.

## Формат

TSV (tab-separated), один рядок — один заголовок + дані:

```
game_key<TAB>rel_path<TAB>expected
```

- `game_key` — стабільний ідентифікатор гри: `steam:<appid>`, якщо Steam
  appid відомий, інакше `steam:noid:<санітизована_назва>`.
- `rel_path` — шлях файлу відносно кореня встановлення гри, роздільник `\`
  (як повертає `scanner::scan_dir`).
- `expected` — чернеткова мітка, одна з:
  - `audio` — озвучка/аудіо-локалізація (звукові банки, VO);
  - `text` — тексти/субтитри/UI-рядки;
  - `video` — відео-локалізація (озвучені ролики/cutscenes);
  - `font` — мовно-специфічні шрифти;
  - `unknown` — явно мовний файл, але тип активу неоднозначний
    (потребує рішення движка/людини);
  - `none` — НЕ локалізація: звичайний ігровий ресурс, чий шлях лише
    випадково збігається з мовним токеном (пастка для детектора), або
    мова зі keep-list (`en`/`uk`), яку рушій ніколи не повинен пропонувати
    до видалення.

## Як інструмент знаходить кандидатів

Для кожного файлу шлях розбивається на сегменти (`\`/`/`), кожен сегмент —
на токени за роздільниками `_ - . ( ) [ ] пробіл` і межами CamelCase
(`SpanishNation` → `Spanish`, `Nation`). Токени (і, окремо, необрізані
сегменти — для locale-тегів на кшталт `en-US`, де дефіс є частиною
патерну) звіряються зі словниками, у порядку пріоритету:

1. **full_name** — повні назви мов англійською (`english`, `spanish`, …);
2. **steam_name** — Steam-специфічні імена (`koreana`, `schinese`,
   `tchinese`, `latam`);
3. **autonym** — рідні назви (`deutsch`, `francais`, `espanol`, `italiano`,
   `polski`, `portugues`);
4. **locale_tag** — патерн `[a-zA-Z]{2,3}[-_][a-zA-Z]{2}` (`en-us`, `pt_BR`,
   `zh-CN`), **прийнятий лише якщо префікс — розпізнана мова** (це
   відсіює випадкові збіги на кшталт `non-eu`, `read-me`);
5. **iso3** — трибуквені ISO-коди (`spa`, `deu`, `fra`, `ita`, `pol`, `rus`,
   `jpn`, `kor`, `chi`, `zho`, `por`, `ukr`, `eng`) як цілий токен;
6. **iso2** — двобуквені ISO-коди (`es`, `de`, `fr`, `it`, `pl`, `ru`, `ja`,
   `ko`, `zh`, `pt`, `cs`, `tr`, `nl`, `sv`, `no`, `da`, `fi`, `el`, `ro`,
   `bg`, `hu`, `th`, `vi`) — **лише** як цілий (уже delimiter-обмежений)
   токен, ніколи як підрядок довшого слова.

Для одного файлу береться лише перший (найвищий за пріоритетом) збіг —
рядок корпусу відображає саме цей збіг, хоча в шляху міг траплятися й
інший мовний "шум".

## Правила чернеткової розмітки (`expected`), у порядку застосування

1. **Keep-list** — якщо розпізнана мова канонічно `en` або `uk` (через
   `english`/`eng`/`en-*` або `ukrainian`/`ukr`/`uk-*`) → **`none`**,
   незалежно від будь-яких маркерів (навіть якщо поруч є `sound`/`text`
   тощо — keep-list ніколи не позначається до видалення).
2. **Негативний маркер ігрового вмісту** у шляху (`art`, `models`,
   `textures`, `units`, `buildings`, `history`, `decisions`, `events`,
   `missions`, `maps`, `music`, `scripts`) → **`none`**.
3. **Аудіо-маркер** (`sound`, `soundbanks`, `voice`, `vo`, `audio`,
   `speech`, `dub`) у шляху → **`audio`**.
4. **Відео**: відео-маркер у шляху (`movies`, `movie`, `videos`, `video`,
   `cinematics`, `cutscenes`, `fmv`) **АБО** відео-розширення файлу
   (`.bik`, `.bk2`, `.usm`, `.wmv`, `.webm`, `.ogv`) за умови, що мовний
   токен знайдено саме в **імені файлу** (не лише в батьківській теці) →
   **`video`**.
5. **Текст-маркер** (`text`, `strings`, `subtitles`, `caption`, `loc`,
   `localization`, `lang`, `language`, `l10n`) у шляху → **`text`**.
6. **Шрифт**: font-маркер (`font`, `fonts`) **АБО** шрифтове розширення
   (`.ttf`, `.otf`, `.fnt`) за умови мовного токена в імені файлу →
   **`font`**.
7. **iso2/iso3 без контексту**: якщо збіг типу `iso2`/`iso3` і немає
   жодного маркера з (2)–(6), і не спрацювала евристика "мовної сім'ї"
   (нижче) → **`none`** (короткі коди без підтримки — найчастіше звичайні
   слова: `it`, `no`, `de`, `pl`…).
8. **Інше неоднозначне** (в т.ч. `iso2`/`iso3` з підтвердженою "мовною
   сім'єю", і будь-який `full_name`/`steam_name`/`autonym`/`locale_tag` без
   маркера) → **`unknown`** — явно мовний токен, тип активу невідомий,
   потребує рішення движка/людини.

**Примітка:** `movies`/`video` НЕ входять до негативних маркерів (на
відміну від `music`/`textures`, які лишаються негативними) — вміст тек
`Movies`/`Videos` типово саме локалізований відео-контент, а не звичайний
ігровий ресурс.

### Евристика "мовної сім'ї" (спрощена)

У межах однієї гри кандидати групуються за батьківською текою
(`rel_path` без останнього сегмента). Якщо в одній теці зустрічається
**≥3 різних канонічних мов** серед кандидатів — це вважається "мовним
набором", що для iso2/iso3-збігів піднімає мітку з `none` до
`unknown` (сигнал є, але тип активу автоматично не визначається).
Це наближення на рівні директорії, а не точне порівняння "файли, що
відрізняються лише мовним токеном" — за потреби рушій легко перевірити
точніше.

## Балансування та ліміти

- З `G:\`, `H:\` та `d:\...\steam` беруться всі ігри з кандидатами.
- З `F:\SteamLibrary` (набагато більшої за інші) — вибірка: перші 40 ігор
  за алфавітом із кандидатами + всі "мовно-багаті" ігри з ≥50 кандидатами
  (обрано 376 з 838 F-ігор із кандидатами).
- Далі дворівнева рівномірна (stride) вибірка: не більше 150 рядків на
  гру, потім не більше 15000 рядків сумарно. Просте обрізання голови
  списку заповнило б увесь ліміт першими двома-трьома іграми (одна гра
  нерідко має 50–150 тис. кандидатів).

Фінальні метрики рушія проти цього корпусу (`cargo test -p

лише в сім'ї, файл без токена не флагується) не варте компромісу.

## Застереження

- **Мітки більше не суто чернеткові** для ~1030 рядків: вони виправлені
  вручну/скриптом за результатами калібрування рушія (див. вище). Інші
  ~13970 рядків лишаються чернетковою автоматичною розміткою — не
  остаточна істина, особливо рядки `unknown` та межові
  `none`/`audio`/`text`/`video`/`font`.
- Правила чернетки навмисно консервативні: при сумніві — `unknown`, а не
  хибне `audio`/`text`/`video`/`font`.
- `iso2`-збіги — найризикованіша категорія: часто це звичайні слова
  (`it`, `no`, `de`, `pl`…), тому вони позначені `none` без сильного
  контексту в НЕвиправлених рядках.
- Розмір `corpus.tsv` обмежено ~15000 рядків; бібліотека `F:\SteamLibrary`
  (набагато більша за інші) внесена не повністю — див. "Балансування та
  ліміти" вище. Це також означає, що евристика "мовної сім'ї" рушія іноді
  недооцінюється в цьому корпусі: сусідні файли тієї самої родини могли
  потрапити по різні боки вибірки stride/ліміту і не потрапити в один і той
  же `game_key`-зріз, тоді як у реальній повній бібліотеці вони лежали б в
  одній теці разом.
- Систематичні хиби чернеткової розмітки, знайдені калібруванням і ВЖЕ
  ВИПРАВЛЕНІ в `corpus.tsv` (лишено тут як історія/контекст для майбутніх
  прогонів `corpus_collect.rs`):
  - маркери порівнювались з токеном точно, тому `languages` (множина) не
    збігалася з `language` — напр.
    `STASIS2_Data\...\languages\es\descriptions.csv` була `none`, виправлено
    на `text`;
  - iso2/iso3 + маркер без "мовної сім'ї" давали хибні мітки на звичайних
    ігрових abbreviations: `valve\sound\player\pl_*.wav` (`pl_` = "player"),
    `valve\sound\holo\tr_*.wav` (`tr_` = якийсь ігровий префікс, не
    турецька), `valve\sound\vox\no.wav` (слово "no", не норвезька) —
    виправлено на `none`; аналогічно `AvenirNextWorld-*It.ttf` (`It` =
    Italic, не італійська) і `JetBrainsMonoNL-*.ttf` (`NL` = No Ligatures,
    не нідерландська);
  - `.srt`/`.vtt`/`.xml`-субтитри у теці `video\`/`Cutscenes\` позначались
    `video`, хоча по суті це `text` — виправлено (`rerelease\baseq2\video\
    eou6__ru.srt` та ще ~230 подібних рядків);
  - "мовна сім'я" рахувалась лише в межах ОДНІЄЇ батьківської теки без
    перевірки сусідніх директорій, тому мовні ТЕКИ-сусіди (`de\`, `it\`,
    `pl\` поряд — класичні .NET satellite assemblies:
    `de\ReachFramework.resources.dll`, локалізовані `docs\EA Help\Da\ De\
    Es\...` мануали) лишались `none` — виправлено на `unknown`/специфічний
    тип (рушій реалізує цю евристику на рівні директорій і сімейну
    евристику зі спільною позицією токена в імені файлу, див.
    `langdetect/family.rs`).
